# ProVouchers Docs

Documentation site for [ProVouchers](https://github.com/alazso/ProVouchers),
built with Next.js and Fumadocs. Served at https://alaz.so/provouchers.

## Development

```bash
npm install
npm run dev
```

The site runs at http://localhost:3000/provouchers.

## Content

Documentation pages live in `content/docs/` as MDX. The navigation order is
controlled by `content/docs/meta.json`.

## Build

```bash
npm run build
```
